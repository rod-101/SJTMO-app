# 🚦 San Jose Traffic Management System (SJTMS)

## 📌 Overview
The **San Jose Traffic Management System (SJTMS)** is a web-based application designed to streamline the process of managing traffic violations—from apprehension to resolution.

It provides a centralized platform for traffic enforcers and administrators to efficiently record, monitor, and resolve violations, improving accuracy, accountability, and transparency in traffic operations.

---

## 🎯 Features

- 🚓 **Violation Management** – Record and manage traffic violations in real-time  
- 👮 **Enforcer Tracking** – Assign and monitor enforcer activity  
- 📊 **Dashboard** – View summaries and status of violations  
- 🗂️ **Dynamic Violation Types** – Add and manage violation categories  
- 🔐 **Authentication** – Secure login with role-based access (Admin, Enforcer)  

---

## 🏗️ Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js + Express.js  
- **Database:** PostgreSQL  
- **Deployment:** Render
